# Rakyzu Music Android 0.5.5

This is the cumulative `0.5.1`–`0.5.5` listener-controlled Queue milestone, versionCode 51.

## Included work

- Track context sheets in Search, Artist, and Album detail can now play a track next or add it
  to the existing queue. Duplicate requests are deterministic: add-to-queue does not duplicate a
  media ID, and play-next repositions an existing item directly after the active track.
- Now Playing exposes explicit move-earlier, move-later, remove, and clear actions with
  track-specific TalkBack labels. Queue changes continue through the Media3 controller and the
  account-scoped Room persistence path.
- A signed-in account restores its saved queue after process death in a paused state. Restoration
  bounds entries and removes malformed or duplicate legacy items before handing them to Media3;
  it never resumes audio without a listener action.
- Playback has an explicit `ExplicitQueueOnly` policy: Rakyzu does not append recommendation
  media automatically after the listener's queue. Now Playing communicates that boundary.
- The snapshot now includes a local `This device` playback-device state. It intentionally exposes
  no remote-control or transfer capability.
- Private playlist artwork authorization denials now remain non-disclosing `404` responses instead
  of being misclassified as service outages.

## Validation scope

The release gate runs Android unit tests, affected-module lint, a signed debug build, Android-test
APK compilation, Worker typecheck/tests/dry-run, linked Supabase migration dry-run, a secret scan,
and post-publication artifact/CI checks. The unsigned release build remains a CI release-gate
responsibility until production signing is provisioned. Final evidence is recorded in
`docs/WORK_SESSION.md`.

## Security and privacy

No credential, token, media URL, or listener identifier is persisted in queue metadata. The
Android client continues to request media through the authenticated Worker boundary. Remote
device controls are not advertised or implemented by this milestone.
