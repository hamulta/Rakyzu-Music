# Rakyzu Music Android 0.0.2

## Scope

- Replaced the static bottom bar with a Material 3 adaptive navigation suite that selects a navigation bar or rail according to the available window space.
- Added type-safe, saveable Navigation 3 routes for Home, Search, and Your Library.
- Moved the mini player into the app shell so it remains available across top-level destinations.
- Added semantic headings, descriptive playback actions, decorative image handling, and a minimum 48 dp play target.
- Added unit coverage for top-level navigation behavior and an Android UI test for navigation heading semantics.
