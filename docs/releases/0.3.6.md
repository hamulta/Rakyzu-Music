# Rakyzu Music Android 0.3.6

## Scope

This cumulative release completes the approved `0.3.4`–`0.3.6` Library batch.

- Saved albums load protected artwork through the authenticated Rakyzu API and credential-free Coil cache keys.
- Saved-album and followed-artist rows retain canonical typed navigation into their offline detail destinations.
- Empty Library, filtered-empty, and search-empty states provide contextual copy and a direct recovery path to Search.
- Like, Save, and Follow mutations update Room optimistically and persist in a listener-scoped durable outbox.
- Repeated offline actions for one item coalesce to the latest intent; exact acknowledgements cannot remove a newer mutation.
- Transient delivery failures remain queued with attempt metadata, and server rejection rolls back the optimistic selection.
- Initial Library synchronization uses validated keyset pages capped at 50 rows.
- Later refreshes consume an ordered RLS-isolated cursor stream, including deletion tombstones, and resume from the last applied sequence.
