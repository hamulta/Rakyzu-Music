# Rakyzu Music Android 0.0.3

## Scope

- Provisioned a fresh, healthy Rakyzu Music Android Supabase project in Singapore on PostgreSQL 17.
- Added the first ordered forward migration with a private helper schema and owner-scoped `profiles` table.
- Enabled and forced Row Level Security, denied anonymous access, and limited authenticated clients to reading and updating their own display name.
- Added a security-definer signup trigger with an empty search path so each Auth user receives one profile without exposing client insert privileges.
- Added pgTAP schema and positive/negative RLS tests plus remote schema linting.
- Added an isolated Database CI workflow that validates migrations before deploying pending migrations from `main`.

## Release identity

- Application ID: `my.id.rakyzumusic`
- Version code: `3`
- Version name: `0.0.3`
- Debug artifact: `Rakyzu-Music-0.0.3-debug.apk`

## Quality gates

The release is accepted only when Android tests/lint/build and database migration replay/pgTAP/lint workflows pass. Database deployment uses only encrypted GitHub Actions secrets and forward migrations.
