# Rakyzu Music Android 0.4.10

This is the cumulative 0.4.5–0.4.10 Playlist milestone, versionCode 45.

## Highlights

- Single-use seven-day editor/viewer invites, member revocation, leave, and Android Sharesheet support.
- Private/public visibility and public following with server-enforced abuse-resistant limits.
- Durable Room mutation outbox, idempotent operation receipts, and explicit conflict recovery.
- Cursor-paginated playlist collections and bounded incremental detail loading.
- Adaptive Playlist UI, 48dp controls, privacy-safe diagnostics, and role-aware TalkBack state.
- Configured-build and in-APK configuration gates prevent publishing the unusable auth state seen in the prior local test APK.
- Collaborator artwork reads resolve the canonical owner; writes and deletion remain owner-only.

## Security and data handling

All collaboration tables force Row Level Security. Authenticated clients receive no direct
write grants; bounded RPCs validate identity, role, playlist revision, UUIDs, expiration and
limits. Invite tokens, account/content identifiers, titles, URLs, credentials, raw errors and
payloads are excluded from Playlist diagnostics. Privileged Supabase, Cloudflare and R2
credentials remain outside the APK and repository.

Final CI/CD, connected-device, Appetize, deployment, and downloaded-artifact evidence is
recorded in the release audit attached to the GitHub release.
