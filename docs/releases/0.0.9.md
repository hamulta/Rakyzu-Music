# Rakyzu Music Android 0.0.9

## Scope

- Made the Media3 timeline the playback queue source of truth and added full-catalog queue startup from Home.
- Added immutable queue, current-index, duration, position, buffer, transport-availability, and playback-error state for Compose consumers.
- Added previous, next, queue-item selection, and bounded seek commands through the application-scoped MediaController.
- Added a playback-only progress sampler that updates while audio is active and stops when progress is static.
- Expanded the compact player with live progress, next-track action, and entry into Now Playing.
- Added the independently owned `feature:player` module with Rakyzu-branded artwork, track and album details, seeking, elapsed/total time, transport controls, failure state, and queue navigation.
- Added navigation guards so Now Playing cannot be duplicated and dismissal preserves the previous top-level destination.
- Added unit coverage for progress normalization, buffered progress, time formatting, and Now Playing back-stack behavior.

## Security and content boundary

- The queue stores canonical track UUIDs and public display metadata only; bearer sessions remain resolved just in time for each HTTPS media request.
- Seek, skip, and queue-selection actions operate through the in-process MediaController and never expose Worker or R2 credentials.
- Invalid queue input and unavailable media degrade to bounded UI errors without revealing backend responses or storage details.
- The private R2 media bucket intentionally remains empty until rights-cleared Rakyzu Music audio is supplied.
