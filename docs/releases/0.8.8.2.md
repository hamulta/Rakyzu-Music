# Rakyzu Music Android 0.8.8.2

This Android Explore milestone uses application ID `my.id.rakyzumusic`, versionName `0.8.8.2`,
versionCode `108`, min SDK 26, target/compile SDK 37, and Room schema 13. The four-part public
release version remains represented by versionName, tag, and artifact name; Android's integer
versionCode remains monotonically increasing.

## Interactive Explore discovery

- Adds a branded Explore landing surface with compact private Recommended For You cards that play
  directly and never fabricate placeholder songs.
- Seeds four real Your Top Genres groups and six real Browse All groups with published catalog
  membership, bounded server placement ranges, ambient artwork colors, and real group detail queues.
- Adds long-press staff editing for names, labels, colors, visibility, position, artwork, ordered
  membership (1–50 tracks), and deletion. Permission checks remain server authoritative.
- Records one privacy-preserving group-open receipt per listener/shelf/day and uses the resulting
  global score to rank equalized global cards while preserving deterministic staff position ties.
- Adds the branded notification primer before the native Android notification request after auth;
  storage/media permissions remain requested only from upload actions.

## Data and release safety

- Room 12→13 is additive and preserves existing catalog/editorial rows while adding card label,
  color, and global score metadata.
- Supabase migrations are forward-only with forced RLS for engagement receipts and permission-checked
  RPCs for all editorial mutations. No Supabase service key, Cloudflare token, or R2 credential is
  included in the APK.
