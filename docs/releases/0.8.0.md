# Rakyzu Music Android 0.8.0

This cumulative `0.7.8` and `0.8.0` Android prerelease uses application ID
`my.id.rakyzumusic`, versionName `0.8.0`, versionCode `98`, min SDK 26, and target SDK 37.

## First-party lyrics

- Rakyzu Lyrics Studio supports manual text and editable `.LRC`/`.SRT` imports.
- Parsing is deterministic and bounded to 1 MiB, 2,000 lyric lines, 500 characters per line, and
  a 24-hour timestamp domain.
- Manager, C-Level, and CEO staff can save drafts, publish, edit, and delete lyrics.
- Scoped Artist editors can prepare drafts for their own editable tracks but cannot publish.
- Drafts and immutable revisions are never exposed through listener or direct-table access.
- Published lyric attribution is `Rakyzu Music`; no third-party lyrics API is used.
