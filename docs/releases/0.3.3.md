# Rakyzu Music Android 0.3.3

## Scope

This cumulative release completes the approved `0.3.1`–`0.3.3` Library batch.

- Home featured and shelf tracks expose consistent Like, album Save, and artist Follow entry points with pending-action protection.
- Now Playing exposes direct Like, Save, and Follow actions backed by canonical IDs retained in Media3 queue metadata.
- Your Library adds bounded local search, type filters, Recently added/Oldest added/A–Z sort choices, explicit no-result recovery, and listener-shell saved-state restoration.
- Room selection timestamps now survive projection into the resolved Library snapshot, fixing true Recently added and Oldest added ordering.
- Liked Songs bulk playback and individual row playback use the exact visible, filtered, sorted queue with a deterministic start index.
- Accessibility coverage guards Library controls, bulk queue behavior, and Home Library actions.

- Corrected the `0.3.0` quality-gate wording from Room migration coverage to the accurate Room schema/export coverage; Supabase forward-migration replay remains covered independently.
- Pinned the remaining Database and Worker workflow actions to immutable reviewed commit SHAs, matching the documented supply-chain policy.
