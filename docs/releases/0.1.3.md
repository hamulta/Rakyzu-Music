# Rakyzu Music Android 0.1.3

## Scope

- Added relative Home feed freshness metadata backed by the persisted Room catalog synchronization timestamp.
- Classified a saved catalog as stale after 24 hours without a successful synchronization.
- Added a distinct stale-cache warning when refresh fails while keeping recent saved catalogs accurately labeled.
- Handled missing and future synchronization timestamps without negative ages or misleading freshness claims.
- Added deterministic clock injection for Home state tests without changing the production repository boundary.
- Added unit and Compose instrumentation coverage for fresh, stale, missing, and future timestamp states.

## Security and privacy

- This patch adds no permission, endpoint, persistence field, analytics event, or user-data collection.
- Freshness is derived only from the existing local catalog synchronization timestamp; no listener activity or device identifier is exposed.
- Existing Supabase RLS, encrypted session storage, private R2 delivery, and account-isolated listening history remain unchanged.
