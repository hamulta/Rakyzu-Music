# Rakyzu Music Android 0.0.4

## Scope

- Added branded email sign-in and registration surfaces with accessible Compose semantics and unidirectional UI state.
- Added a Supabase Auth repository driven by the SDK session-status flow, including safe error mapping and fail-closed public configuration validation.
- Added PKCE confirmation callbacks through `my.id.rakyzumusic://auth` and session-gated application navigation.
- Encrypted access tokens, refresh tokens, and PKCE verifiers with AES-GCM using a non-exportable Android Keystore key.
- Added current-device logout from the profile sheet while preserving sessions on other devices.
- Configured hosted Supabase Auth for verified email accounts, an eight-character lower/upper/digit password policy, refresh-token rotation, and a ten-second reuse window.
- Added focused unit tests for credentials, configuration, authentication state handling, and registration confirmation.

## Release identity

- Application ID: `my.id.rakyzumusic`
- Version code: `4`
- Version name: `0.0.4`
- Debug artifact: `Rakyzu-Music-0.0.4-debug.apk`

## Configuration

Android accepts only `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` through generated BuildConfig values. GitHub Actions reads both from encrypted repository secrets. Privileged Supabase, Cloudflare, and R2 credentials are excluded from the APK.

## Quality gates

The release is accepted only after core and feature unit tests, Android app unit tests, Android-test source compilation, lint, debug APK assembly, and debug test APK assembly all pass. The hosted Auth configuration must also match the documented email, redirect, password, and refresh-token controls.
