# Rakyzu Music Android 0.5.15

This cumulative `0.5.11`–`0.5.15` organization administration release uses versionCode 61.

## Included

- Fixed ranked roles for Officer, Supervisor, Manager, C-Level Executive, and CEO.
- Explicit permission matrix, active account assignments, hierarchy-safe changes, and protection
  against disabling the final active CEO.
- Forced-RLS moderation cases/actions, staff audit evidence, and private R2 media inventory.
- A role-gated Android Control Room for moderation, exact-email staff assignments without manual
  UUID lookup, artist/album/track drafts, bounded MP3 upload, and album publication.
- Worker-side JWT, permission, input, content-type, size, MP3 signature, exact object-key, and RPC
  enforcement. No privileged database or Cloudflare credential is shipped in Android.
- Atomic catalog publication only after every track has a registered standard-quality audio object.

## Role boundaries

- Officer: view, open, claim, and escalate moderation work.
- Supervisor: Officer capabilities plus final action/dismiss decisions.
- Manager: Supervisor capabilities plus lower-rank assignment and catalog drafting.
- C-Level Executive: Manager capabilities plus audio upload and publication authority.
- CEO: the complete permission set and authority over every organization rank.

## Acceptance boundary

Release requires all Android unit tests, lint, debug and Android-test APK assembly, R8 validation,
Worker type/binding/tests/dry-run, isolated database migration replay/pgTAP/lint, linked forward
deployment, live role-context and denial checks, tracked-source/APK secret scans, CI success, and
byte-identical CI/Release APK verification. The release does not claim Appetize, emulator, ADB, or
physical-device execution.
