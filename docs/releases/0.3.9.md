# Rakyzu Music Android 0.3.9

## Scope

This cumulative release completes the approved `0.3.7`–`0.3.9` Library batch.

- Library freshness is derived from the last verified Room synchronization and clearly marks saved data stale after 24 hours.
- Refresh requests coalesce, transient network/service failures retry only twice with bounded delays, and invalid requests or payloads fail immediately.
- Offline refreshes and queued mutations recover once when Android reports a validated default network, without polling.
- Compact screens and large text use an adaptive Library policy with expanded rows, flexible text lines, and stable artwork geometry.
- TalkBack receives explicit headings, live status, selected filter/sort state, freshness, sync, playback, removal, and album/artist navigation contracts.
- Filtered and sorted Library content is derived once per immutable render input; a 5,000-track regression protects deterministic behavior.
- Process-local diagnostics publish only coarse counts and bounded lifecycle enums. Listener/content identifiers, titles, queries, URLs, tokens, payloads, and raw exceptions are excluded by type.
