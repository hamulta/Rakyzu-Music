# Rakyzu Music Android 0.1.2

## Scope

- Added track-specific accessibility action labels to featured and shelf playback controls.
- Declared playback controls as buttons without changing their queue callbacks.
- Grouped each shelf for accessibility traversal and assigned track traversal order from the Media3 queue index.
- Enforced an explicit minimum 48dp interactive height for profile, filters, retry, refresh, featured playback, and track cards.
- Added a normalized playback-label helper so surrounding catalog whitespace is never announced.
- Added Compose instrumentation coverage for action labels, traversal indices, queue selection, and touch-target dimensions.

## Security and privacy

- This patch adds no permission, endpoint, persistence field, analytics event, or user-data collection.
- Accessibility labels are derived only from already-visible validated catalog titles.
- Existing Supabase RLS, encrypted session storage, private R2 delivery, and account-isolated listening history remain unchanged.

The published GitHub Release asset must exactly match the verified CI artifact before tagging `v0.1.2`.
