# Rakyzu Music Android 0.8.8

This cumulative `0.8.1`–`0.8.8` Android prerelease uses application ID
`my.id.rakyzumusic`, versionName `0.8.8`, versionCode `106`, min SDK 26, target SDK 37, and Room
schema 12.

## Private personalization

- Weighted account-scoped listening history remains on the device and exposes bounded play counts.
- Rakyzu Mixes, track radio, Artist radio, and explainable recommendations are generated locally;
  no third-party recommendation API is used.
- Familiar, Balanced, and Explore modes rotate deterministically by account and UTC day while
  limiting repeated Artists.
- Listeners can pause personalization, hide a recommendation, exclude or restore a track as a
  taste signal, and transactionally reset local history/settings without changing their Library.
- Home adapts to compact, medium, expanded, and large-text layouts and retains accessible headings,
  traversal groups, live announcements, and minimum touch targets.

## Privacy and resilience

- Room automatically migrates schema 11 to 12 and preserves earlier listening rows.
- Feedback mutations validate the account/track boundary, counters are capped, UI failures are
  contained, and diagnostics expose only coarse count buckets—not account IDs, track IDs, URLs, or
  exact listening totals.
- Supabase schema/RLS is unchanged because private personalization never leaves the Android device.
