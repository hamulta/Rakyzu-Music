# Rakyzu Music Android 0.1.4

## Scope

- Added a deterministic Home layout policy for compact screens and large accessibility text.
- Activated adaptive mode below 360dp width or at a font scale of 1.3x and above.
- Stacked the featured Home card vertically in adaptive mode so artwork and playback copy no longer compete for horizontal space.
- Reduced compact-screen edge padding and widened track cards up to 220dp.
- Allowed two lines for track titles and metadata in adaptive shelves while retaining the denser standard layout.
- Added unit coverage for width/font-scale breakpoints and Compose coverage for adaptive card dimensions.

## Security and privacy

- This patch adds no permission, endpoint, persistence field, analytics event, or user-data collection.
- Layout selection uses only the local Compose width constraint and font scale; neither value is transmitted or persisted.
- Existing Supabase RLS, encrypted session storage, private R2 delivery, and account-isolated listening history remain unchanged.

The release is accepted only after all Android unit tests, Android lint, debug APK assembly, Compose instrumentation APK compilation, all debug test APK assemblies, minified R8 release assembly, manifest and signature verification, credential scanning, and final GitHub Actions success. The published GitHub Release asset must exactly match the verified CI artifact before tagging `v0.1.4`.
