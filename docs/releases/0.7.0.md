# Rakyzu Music Android 0.7.0

This cumulative `0.6.6`–`0.7.0` prerelease uses application ID `my.id.rakyzumusic`,
versionName `0.7.0`, and versionCode `89`.

## Offline resilience

- A successful catalog refresh marks removed tracks unavailable without deleting their encrypted
  bytes; restored tracks recover deterministically when their license and file remain valid.
- The Rakyzu API emits a bounded content revision derived from the authorized R2 object, and Room
  10 stores it without exposing object keys or direct storage URLs.
- Each account explicitly chooses whether encrypted downloads remain on this device after sign-out.
  Removal is the privacy-preserving default; work is cancelled before the local Auth session ends.
- Completed files are decrypted to EOF during integrity audit, invalid/expired items fail closed,
  transfers are limited to two concurrent executions, automatic retries stop after five attempts,
  an explicit manual retry starts a fresh bounded attempt window, and collection/account quotas
  prevent unbounded work.

## Android experience and 0.7 foundation

- Download rows reflow on compact screens and at large font scales, expose stable status text,
  48dp destructive actions, progress semantics, and explicit unavailable-content guidance.
- Diagnostics are aggregate-only and contain no title, account, track, filesystem, or token data.
- Bounded domain contracts now represent licensed lyrics, normalized credits, release-notification
  preferences, and validated track-share URIs. Now Playing exposes the Android Sharesheet without
  granting another app access to offline media or credentials.
