# Rakyzu Music Android 0.8.8.4

This corrective Android patch uses application ID `my.id.rakyzumusic`, versionName `0.8.8.4`,
and versionCode `110`.

## Artwork and card corrections

- Explore Card Groups always render the tilted mini-album cover treatment. If an album or custom
  artwork request is unavailable, the cover remains visible as a framed Rakyzu fallback instead
  of disappearing into the card background.
- Home and Explore editorial artwork requests are invalidated after the server confirms a successful
  upload or deletion, so replacement images are fetched instead of retaining the first 404 result.
- The account sheet shows the selected profile image immediately and falls back to the authenticated
  R2 avatar after the profile context reports the new avatar version. Failed uploads remove the
  optimistic preview and surface the existing error message.

## Validation and publication

The source is validated by the path-filtered GitHub Actions Android workflow. Local Gradle execution
is intentionally skipped under the active CEO instruction; no emulator/Appetize result is claimed.
The published debug APK must match the successful CI artifact byte-for-byte before tag/release
publication.
