# Rakyzu Music Android 0.1.8

## Scope

- Restored the selected Home filter after Activity or saved-instance recreation.
- Restored the vertical Home feed position and the horizontal position of every track shelf.
- Restored the filter row's horizontal position through the same Compose list-state contract.
- Replaced display-label persistence with stable filter keys and a safe Music fallback for unknown saved values.
- Added explicit keys for Home header, filters, freshness, featured content, status, empty state, recently played, editorial shelves, new releases, all tracks, filters, and track cards.
- Scoped all Home saveable state to the authenticated listener so an account switch starts with fresh navigation state.
- Added deterministic unit coverage for filter key restoration and Compose instrumentation coverage for filter, vertical-list, and horizontal-shelf saved-instance restoration.

## Security and privacy

- Saved-instance state contains only a bounded filter key plus lazy-list indices and pixel offsets.
- Supabase sessions, authorization headers, catalog payloads, artwork, and playback queues are not added to the Home saved-state bundle.
- Listener-scoped composition identity prevents restored filter or scroll coordinates from crossing account boundaries.
- Existing encrypted session storage, Supabase RLS, private R2 delivery, and cleartext-traffic rejection remain unchanged.
- No dangerous Android permission, database migration, Worker change, or Room schema change was added.
